# Публикация FreeChat в RuStore

Эта инструкция покрывает локальную подготовку Android-сборки. Саму загрузку нужно выполнить в RuStore Консоли под аккаунтом разработчика.

## 1. Выбрать package name

Перед первой публикацией задайте финальный уникальный package name. Текущий дефолт проекта для разработки: `com.example.chatapp`, для магазина его лучше заменить.

Пример: `ru.yourcompany.freechat`.

После публикации package name нельзя поменять для обновлений существующего приложения.

## 2. Создать ключ подписи

Если приложение уже публиковалось в другом магазине и вы хотите, чтобы пользователи могли обновляться поверх старой установки, используйте тот же signing key. Для нового приложения можно создать новый ключ:

```powershell
keytool -genkeypair -v -keystore freechat-release.jks -alias freechat -keyalg RSA -keysize 2048 -validity 10000
```

Сохраните `.jks` и пароли в надежном месте. Потеря ключа может заблокировать выпуск обновлений.

## 3. Настроить release.properties

Скопируйте шаблон:

```powershell
Copy-Item release.properties.example release.properties
```

Заполните:

```properties
FREECHAT_APPLICATION_ID=ru.yourcompany.freechat
FREECHAT_VERSION_CODE=1
FREECHAT_VERSION_NAME=1.0.0
FREECHAT_RELEASE_STORE_FILE=freechat-release.jks
FREECHAT_RELEASE_STORE_PASSWORD=...
FREECHAT_RELEASE_KEY_ALIAS=freechat
FREECHAT_RELEASE_KEY_PASSWORD=...
```

`release.properties` и `*.jks` не должны попадать в git.

## 4. Проверить production .env

Перед релизом проверьте корневой `.env`:

- `APP_API_BASE_URL` должен указывать на рабочий HTTPS backend, не на `https://api.example.com/api/`.
- `CHAT_SHARE_PUBLIC_BASE_URL` должен указывать на публичный HTTPS сайт/домен.
- `PUBLIC_INFO_URL` и `SUPPORT_URL` желательно заполнить реальными ссылками.
- OAuth/Telegram/VK параметры должны соответствовать production package/deep links.

## 5. Собрать релиз

Проверки:

```powershell
.\gradlew.bat :app:testDebugUnitTest
```

AAB для RuStore:

```powershell
.\gradlew.bat :app:bundleRelease
```

APK, если нужен именно APK:

```powershell
.\gradlew.bat :app:assembleRelease
```

Ожидаемые файлы:

- `app/build/outputs/bundle/release/app-release.aab`
- `app/build/outputs/apk/release/app-release.apk`

## 6. Что заполнить в RuStore

Базовая карточка:

- Название: `FreeChat`
- Категория: `Общение` или `Полезные инструменты`
- Краткое описание: до 80 символов
- Подробное описание: до 4000 символов
- Иконка: 512x512 PNG/JPG, без прозрачных краев
- Скриншоты: 1-10 PNG/JPG
- Контакты разработчика: email, сайт или VK

Готовый вариант для вставки:

```text
Краткое описание:
AI-чат с файлами, изображениями, голосом и экранным ассистентом.

Подробное описание:
FreeChat - Android-приложение для общения с AI-помощником.

Возможности:
- текстовый AI-чат с историей диалогов;
- работа с изображениями и файлами;
- генерация изображений;
- голосовой ввод;
- режимы поиска, обучения и подбора товаров;
- публичные ссылки на выбранные чаты;
- локальная защита входа с помощью биометрии;
- цифровой ассистент поверх других приложений по запросу пользователя.

AI-запросы обрабатываются через серверную часть приложения. API-ключи AI-провайдеров не хранятся внутри Android-приложения.

Что нового:
Первый релиз FreeChat для Android.
```

Возрастной рейтинг: если режим 18+ остается доступен в релизе, выбирайте соответствующее взрослое ограничение и проверьте требования RuStore к такому контенту. Если не хотите проходить модерацию как adult-приложение, отключите этот режим до публикации.

## 7. Обоснования разрешений

В RuStore нужно заполнить безопасность данных и чувствительные разрешения. Для текущего манифеста можно использовать такие формулировки:

- `CAMERA`: съемка и прикрепление фото для анализа в чате.
- `RECORD_AUDIO`: голосовой ввод запросов.
- `READ_EXTERNAL_STORAGE`, `READ_MEDIA_IMAGES`, `READ_MEDIA_VISUAL_USER_SELECTED`: выбор изображений и файлов для вложений.
- `POST_NOTIFICATIONS`: уведомления о работе ассистента и статусе ответа.
- `USE_BIOMETRIC`: локальная защита входа в приложение.
- `SYSTEM_ALERT_WINDOW`: показ цифрового ассистента поверх других приложений по запросу пользователя.
- `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_MEDIA_PROJECTION`, `FOREGROUND_SERVICE_SPECIAL_USE`: работа ассистента и временный захват экрана после явного подтверждения пользователя.
- `RECEIVE_BOOT_COMPLETED`: восстановление виджета/локальных функций после перезагрузки.
- `INTERNET`: обмен с backend API.

Не заявляйте сбор данных, которых приложение фактически не собирает. Если backend хранит аккаунт, чаты, файлы или идентификаторы, это нужно отразить в декларации данных.

## 8. Загрузка

В RuStore Консоли:

1. `Приложения` -> `Добавить приложение`.
2. Введите `FreeChat`.
3. Откройте приложение -> `Загрузить версию`.
4. Загрузите `AAB` или `APK`.
5. Заполните карточку, данные безопасности и "Что нового".
6. Отправьте на модерацию.
